# 🗑️ Pasta de descarte — pode apagar tudo isto

Esta pasta reúne o que **não é mais usado** no projeto, separado aqui para você
revisar e apagar com segurança. Nada aqui dentro é referenciado pelo sistema atual.

## O que tem aqui e por quê

- **`DevBurguer-Mobile/`** — o app do garçom **antigo**, feito em React Native / Expo.
  Foi **substituído** pelo app nativo em Java (`DevBurguerAppGarcom/`), que é o oficial
  agora. Este protótipo Expo não é mais usado.

- **`PIM_DevBurguer_3.docx`** — a documentação do **PIM III** (entrega anterior).
  A documentação vigente é o `documentacao/pim/PIM_IV_DevBurguer.docx`.

- **`assets-descartaveis/`** — imagens de rascunho/testes que estavam soltas na pasta
  `assets/` da raiz (capturas de tela, imagens geradas, "Sem título"). Os **logos de
  verdade** (`LogotipoLargo.png`, `logoLarge.png`, `fotodev.png`) foram **mantidos**
  em `assets/`.

## Como apagar

Depois de conferir, é só **apagar esta pasta inteira** (`_LIXO_PARA_APAGAR/`).
